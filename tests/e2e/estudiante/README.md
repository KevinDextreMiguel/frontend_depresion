# estudiante/

Specs que requieren sesión de estudiante (storageState `playwright/.auth/estudiante.json`,
generado por `tests/setup/auth.setup.ts`). Corresponde al proyecto Playwright `estudiante`.

HU relevantes: HU0006 (perfil), HU0007–HU0015 (cuestionario autenticado,
guardado de progreso, chatbot), HU0020 (resultado), HU0023/HU0024 (evolución),
HU0034/HU0035 (consentimiento).

**Piloto implementado**: `HU0009/` (CA1, CA2, CA4 — detección de riesgo
suicida, lado estudiante). Ver `docs/e2e-fase3-piloto-informe.md`.

El resto de HU de este proyecto se agrega en siguientes iteraciones.
